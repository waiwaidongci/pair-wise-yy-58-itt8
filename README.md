# pair-wise-yy-58 大型构件吊装三维校核平台

围绕大型转换桁架吊装方案，提供三维场景、时间轴校核、冲突定位、条件评论和多角色签署工作流。页面支持拖动旋转吊装场景、编辑步骤参数、处理规则冲突、恢复本地草稿并锁定发布版本。

## 技术栈

Vue 3、Quasar、Pinia、Vue Router、Apollo Client、GraphQL、Three.js、Vite、TypeScript。

## 运行

```bash
npm install
npm run dev
```

端口：`62058`

```bash
npm run build
```

数据草稿保存在浏览器 `localStorage`，Apollo 内存缓存保存吊装方案版本快照。

## 授权批次（多角色会签）

吊装步骤、条件评论、四角色签署与方案版本通过「授权批次」串联（见 `src/authBatch.ts`）：

- **发起即冻结**：发起批次（`AUTH-V<版本>-<序号>`）时，按每个角色的复核步骤范围对范围内步骤与评论计算确定性指纹并冻结。
- **改动即失效、范围外不连坐**：步骤或评论修改后，只有复核范围覆盖该步骤的角色签署指纹失配作废，需按当前现场内容重算重签；范围外角色签署继续有效。
- **并发先到生效**：两个终端以同一服务端顺序号提交同一角色签署时，模拟服务端原子判重，先到者生效，晚到者被拒且其现场内容保留为草稿，不覆盖现场。
- **失败不留半份**：签署按整批原子提交，故障时事务回滚，本地按批次号恢复到服务端快照。
- **旧草稿迁移、旧版本可查**：缺指纹的旧草稿按当前步骤补齐四角色指纹并记录迁移日志；锁定发布时归档版本快照与签署，旧版本继续可展开查看。

会签页可直接发起批次、签署、演练双终端并发与写入失败；授权日志实时展示批次、失效、冲突与恢复事件。

```bash
npm run verify  # 指纹范围、并发抢占、原子恢复的断言验证
npm run build
```
